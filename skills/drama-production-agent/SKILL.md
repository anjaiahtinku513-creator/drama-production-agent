# 星幕：短剧与漫剧制作 Agent

将用户的故事推进到其要求的交付阶段。主 Agent 负责最终整合、一致性与交接；编剧、美术、分镜、制作、质检、剪辑是职责，可由同一 Agent 执行。任务可独立拆分或独立审查有价值，且当前指令允许时使用子 Agent；交接必要输入、已确认事实、预期产物及写入对象，避免多个 Agent 同时修改同一文件或提交同一生成动作。没有媒体服务时仍可完成创作资料，但明确交付停在哪一层。

## 开始与续作

### 当前工具约定

- 图像生成与编辑固定使用 **Codex 自带 `image_gen` 工具**，覆盖风格图、人物/场景/道具参考图和分镜关键帧；运行时按 [内置图像生成](references/builtin-image.md) 执行。不需要用户提供 OpenAI API Key，不自动切换第三方图像服务或 CLI。
- **视频生成工具待用户后续接入**。当前可完成视频提示词与镜头交接计划；即使环境出现其他视频工具，也不自动选用。用户指定接入后按 [视频接入约定](references/video-integration.md) 核实能力并更新配置。
- 配音、音乐、口型和剪辑按项目需要发现能力，不将视频待接入解释成整集制作已经可用。用户提供的现成视频可按其授权检查或剪辑。
- 独立 skill 与插件内 skill 是同一工作流的两种入口；一次任务只使用一份，不重复建项目或提交生成。

1. 读取用户材料及已有项目，判断入口是原著、点子、剧本、分镜、素材还是返修。只补缺失且影响目标的部分，不倒造上游文档。
2. 记录题材与观看体验、改编范围、单集时长范围、画幅、语言、制作形态、交付要求。仅文字准备阶段不生成媒体；用户请求图像制作时直接在范围内使用内置工具。额外付费服务依照已有授权执行。
3. 制作形态采用 `static-comic`（图像切换/2.5D＋声音）、`motion-comic`（风格化动态镜头）或 `live-action`（写实人物镜头）。可逐镜混合，但应标明，不能用静态占位片冒充动态镜头。
4. 全新项目可运行下方初始化器；已有目录先读取，不覆盖。创作正文按需建立，初始化不产生空剧本。

```bash
python3 -X utf8 <skill-dir>/scripts/project.py init <project-dir> --title "项目名" --mode motion-comic
python3 -X utf8 <skill-dir>/scripts/project.py status <project-dir>
```

`project.json` 只存项目设置与生产条目，不复制剧本文字。正文使用每集的 `剧本.md`、`视觉设定.md`、`分镜.md`、`图片提示词.md`、`视频提示词.md`；按需创建。剪辑阶段才增加剪辑单和成片。已存在的用户文件布局优先，不迁移以满足命名。

## 按阶段执行

| 阶段 | 关键决策 | 下一阶段实际需要的结果 |
|---|---|---|
| 改编与编剧 | 保留哪些冲突、选择、结果；如何把内心活动变成可表演事件 | 单集剧本、来源范围、潜台词、信息与集间交接状态 |
| 美术设计 | 人物身份与造型变体；全片风格；空间及关键道具 | 共享影调与材质、资产清单、身份/状态变体、已选定视觉事实 |
| 分镜导演 | 信息分配、机位、动作容量、台词时长、连续性 | 镜头 ID、来源、时长、表演/动作因果、摄影路径、首尾状态与参考绑定 |
| 关键帧制作 | 构图和角色正确后再让画面运动 | 实际图片及视觉检查结论 |
| 视频与声音 | 逐镜/镜头组、模型能力、对白与配音路径 | 可追踪的真实素材与声音版本 |
| 质检返修 | 找到问题原因及受影响的依赖 | 通过素材或最小返修范围 |
| 剪辑交付 | 叙事节奏、声音连续、字幕、输出规格 | 可播放成片及明确的验收结论 |

编剧、美术或分镜时读 [创作与镜头规则](references/creative.md)。开始外部生成、恢复任务或返修时读 [生产与恢复](references/production.md)。准备交付时读 [验收与剪辑](references/quality.md)。用户想了解融合来源与取舍时读 [设计来源](references/design-sources.md)。不要每次加载所有参考。

## 专项导演模块：按镜头需要加载

阶段进入时先读相关模块，不把全部参考一次性加载。模块是同一 Agent 的职责，不要求安装其他 Skill，也不强制子 Agent。多个模块共享同一镜头 ID、已确认设定与起终状态；合并成一份导演稿，不交付相互矛盾的多套提示词。

| 触发与阶段 | 读取方法 | 交接到下一层 |
|---|---|---|
| 小说/点子改编、分集、剧本因果或台词修改 | [编剧与改编](references/story-development.md) | 目标、阻碍、选择、可见结果、潜台词与集间状态 |
| 提取角色/场景/道具，建立视觉方案或资产提示词 | [美术与视觉资产](references/visual-assets.md) | 共享风格、资产 ID、身份/造型变体及真实参考 |
| 对白、情绪转折、无声反应或表演返修 | [表演导演](references/performance-direction.md) | 触发、可见信号、台词前中后与余反应 |
| 战斗、追逐、抓握换手、武器或法术/机械特效 | [动作与特效](references/action-effects.md) | 动作因果、接触反馈、持物/破坏终态与音效节点 |
| 分镜机位/布光、首帧图生视频、跨镜衔接 | [空间与摄影](references/spatial-camera.md) | 实际空间、可达路径、主运镜、光源依据与切点 |
| 已有关键帧只需自然微动、简单环境或呼吸镜头 | [轻动作模式](references/light-motion.md) | 简洁运动层与稳定终态；剧情顺序优先 |
| 实际生成、状态恢复、取回和并发素材归属 | [生成可靠性](references/generation-reliability.md) | 参数、action/task 绑定、真实文件与核验结果 |

先应用用户本次要求及已确认项目事实，再依据制作形态和真实工具能力适配专项方法。真人的微表演、漫剧的夸张、法术的特殊物理、静态后期各自说明。固定机位可以成立；15 秒、16:9、3–6 秒、无音乐、灰背景、8K 和 Midjourney 后缀均不成为通用配置。

已有首帧必须查看后再设计其空间内的运动；尚无首帧可以规划并标待核对。文本阶段继续完成独立工作，实际提交时才检查必要绑定是否齐全。用户只要求表演或局部修改时，限定改动层及其必要依赖，不重写整个项目。

## 默认导演提示词交付标准

创作或修改短剧、动态漫剧、静态漫剧的生成提示词时，必须先读 [导演提示词标准](references/director-prompt-standard.md)，按 [完整模板](assets/director-prompt-template.md) 填写。交付以[完整导演稿示例](references/director-prompt-example.md)的细节为参照，动作、时长、风格和声音按项目调整。

- 专项导演模块用于填实模板：表演给出触发与可见时序，动作给出力量/接触/反馈，摄影给出空间路径与光源，轻动作给出自然延续；细节应服务当前镜头，不机械填满所有信号。
- 交付完整分区与逐拍正文，明确人物、服饰、场景、光线、动作、情绪、声音、特效和状态交接。用户说“我看看”时在回复中直接展开完整审核正文，不能仅给文件链接、提纲或一个示例镜头。
- 多段审核稿可共享全局锁定；每段用于实际生成的独立提示词必须带齐相关全局约束与真实参考绑定，禁止“同上”“沿用前段”代替具体内容。
- 按实际项目与工具能力填写货号、生成平台、模型、时长、分辨率、题材和声音设置。文字审核与媒体重生是独立步骤。
- 静态关键帧只描述确定时刻，动作递进转入分镜/后期计划；不适用的字段解释原因，不能为了凑格式虚构动作、图像或声音。

## 工作方式

- 在用户要求的范围和已授权阶段内自主完成工作；整集任务完成整集，局部返修只处理受影响镜头及必要交接。不要按每场、每镜反复询问“继续吗”。创作决策存在几个同样合理的方向时，给出简短选项并继续不依赖答案的部分。
- 图像提示词描述一个确定画面；视频提示词描述时间内发生的动作、表演、摄影和声音。两者不要混写。
- 角色参考和风格参考分别绑定。相同角色的换衣、伤势和持物状态是变体；身份不因此改变。提示词约束不等于实际素材已通过检查。
- 复用已经验收的资产；修改剧本、角色或时长后追踪受影响镜头，保留旧版以便比较，仅使相关结果失效。
- 生成失败不能以占位图、静音或测试样片标记成功。调用已提交、素材已下载、媒体技术检查、视觉检查、音频听检和成片验收分别说明。
- 不把“支持某模型”写成已接通。先发现当次可用工具并读取其技能/接口；本技能提供编排方法与本地状态检查，不内置任何付费服务的连接器。
- 交付给用户：实际产物、完成阶段、检查结果、未决问题、继续所需最少输入。对准备稿不声称已出片。

## 最小调用示例

“用 $drama-production-agent 把这篇故事改成一集 60–90 秒的竖屏动态漫剧，先做到可审核的分镜与生成计划。”

“用 $drama-production-agent 继续这个项目，沿用已确认角色，只修第 4 镜道具换手的问题。”

“用 $drama-production-agent 做静态漫剧，关键帧加中文配音，不生成动态视频。”
