# 漫剧导演提示词通用模板

每个生成片段单独填写一份。将实际人物、参考图和动作填入后再提交；不要把括号占位内容直接发给模型。全片约束在每段重复写全，剪辑与审核备注不混入生成指令。

【基础信息】
项目/片名：[填写]
原作与章节：[来源；区分原作事实与改编新增]
项目编号或货号：[适用时填写]
生成平台与模型：[实际设置]
片段与时长：[A/B、各自时长与全片时间范围]
画幅、分辨率：[实际设置]
语言：[对白语言；旁白是否使用]
核心剧情冲突：[谁想做什么，谁如何阻止]
本段必须看清的结果：[一个主要剧情变化]
制作形态：[真人/动态漫剧/静态漫剧；静态稿把时序放入分镜和后期]

【参考图职责锁定】
逐张列出实际提交的参考图或首尾帧字段，不虚构图片编号。
参考1：[固定谁的脸、发型、体型、服装，或完整场景；具体职责]
参考2：[仅在确实存在时填写]
参考冲突优先级：[各类信息分别以哪张图为准]
连续片段首帧：[前段实际生成并检查过的尾帧；待生成时明确待绑定]
禁止迁入：[参考图中不属于本片的背景、文字、拼图布局等]

【摄影机与画质约束】
视觉风格：[明确线条、材质与渲染方式]
摄影机：[项目所需风格；每镜一个主要运动或固定机位；起点→可达路径/速度→跟随对象→落点]
镜头与景深：[全景交代空间、中景看清手和脸；避免互相冲突]
轴线：[人物画面左右、进攻方向、可否越轴]
运动模糊与剪辑：[动作关键姿势可读；切点规则]
画质：[实际分辨率；不使用无法兑现的规格声明]

【文字与声音约束】
画面文字：[字幕、标题是否需要；默认禁止多余水印和图标]
角色声线：[逐人年龄感、音色、节奏；同角色跨段一致]
对白与口型：[说话人、时间、句子；其他人保持合理口部状态]
旁白：[无/指定]
配乐：[无/明确风格与音量]
音效：[与可见动作对应；对白时避让]
翻译：[有外语时逐句提供中文审核译文，不重复朗读]

【人物、服装与道具锁定】
每名角色独立填写：
身份与外貌：[脸型、头发、发饰、体型、年龄感]
服装：[内外层颜色、领口、肩、袖口、腰带、下摆、覆盖长度]
材质：[纹理、厚薄、反光和垂坠，不只写“华丽”]
鞋与饰品：[数量与固定位置]
武器与法宝：[形状、颜色、尺寸、数量、持握手、初始位置]
初始状态：[站位、支撑脚、双手、视线、伤损/灰尘状态]

【场景与光线锁定】
地点：[可见地形、建筑、地面材质]
空间布局：[人物相对位置；前中后景物件的位置]
首帧依据：[已查看的实际首帧/尚未制作的规划；可见入口、路径、遮挡；允许运动与不能凭空新增的内容]
天气与风向：[衣摆、头发、烟尘遵循同一方向]
环境主光：[方向、冷暖、软硬、阴影方向]
轮廓与补光：[方向和强度关系]
法术光：[只在触发时改变局部照明；消退后回到基础光]
连续性：[破损、落地道具和尘土状态跨镜保留]

【动作、服饰与法术物理约束】
动作链：起始姿势→支撑脚→哪只手→运动路径→接触/命中→可见结果→收势。
人物左右手与画面左右分别描述；每拍一个主要动作。
同一只手不能同时持剑、持法宝和结印；切换必须给出过程与时间。
衣料遵循重力与惯性；超自然悬浮需写明法术来源。
法术链：施法者→触发动作→发射位置→轨迹→目标→目标反应→环境反馈→余效消散。
设定特效颜色、尺度、持续时间与遮挡范围，关键动作保持可见。
限制额外肢体、道具复制、武器穿身、站位跳变与没有来源的爆炸。

【分镜与情绪递进】
按本段实际时长逐拍填写，时间连续且总长准确。

第[ ]拍｜[可见动作与剧情作用]
时间：[开始–结束]
构图：[景别、人物可见范围、手脚/武器是否入镜]
构图目的：[观众必须看清哪件事]
摄影机：[单一主要运动及结束机位]
起始状态：[继承上一拍的站位、双手、道具、目光]
触发与潜台词：[因何事件、角色试图达成或隐瞒什么；编译生成稿时转为可见行为]
动作：[完整动作链，左右手分别明确；力量/接触→可见后果→必要反馈→收势]
特效：[完整法术链；明确先后，不堆叠同时发生的事件]
神态：[从目光/呼吸/面部/身体选择本构图看得见的必要信号，强度适配画风]
表演时序：[台词前准备→台词中声音与必要动作→台词后余反应；无声镜头写触发→反应→终态]
情绪递进：[因为什么，从何种情绪变成何种情绪]
对白（角色）：“[短句；没有则写无]”
语气：[重音、停顿、气息与句尾]
中文审核译文：[仅有外语时填写]
音效：[声音与哪个动作节点同步]
结束结果：[观众能直接看到的变化]
交接：[下一镜继承的脚位、双手、道具、光线与运动方向]

【跨段首尾帧与剪辑交接】
前段终态：[机位、角色位置、服装、道具、光线、运动方向]
后段起态：[绑定本轮前段实际尾帧后校准，先继承再推进新动作]
切点：[动作匹配、声音桥或必要的短转场；按实际素材决定]
禁止：[重新开场、左右互换、道具复原、环境重置]

【发布文案】
[一句冲突钩子＋一句看点；与生成指令分开]
[恰好五个相关非品牌标签；与生成指令分开]

【交付审核备注｜不发给生成模型】
分别记录：规格检查、人物服饰一致性、动作和特效可读性、首尾交接、实际听音与口型检查。
提示词中的目标不等于生成结果已达成；未检查的项目明确标注。
