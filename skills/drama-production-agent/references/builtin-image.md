# Codex 内置图像生成

本工作流的图像提供方固定为 `codex_builtin_image_gen`，使用当次公开的 `image_gen` 工具（本环境为 `image_gen.imagegen`），不是自建 API 适配器。执行时先读取可用的 imagegen 技能和工具 schema，以实时说明为准。

## 生成与编辑

1. 为每项资产确定 ID、用途、画幅、风格和不可改变的身份/造型/道具状态。用户仅要提示词时不调用生成。
2. 新图无参考时不传参考图片参数。参考或编辑目标为本地图片时先用 view_image 查看，再按工具支持的 referenced_image_paths 传入；没有本地路径的对话图片按实时工具要求选择最小覆盖范围。两种引用机制不同时使用。
3. 每张输入图明确标注角色身份、场景空间、风格参考或编辑目标。局部返修清楚写出只改什么、保留什么。
4. 批量任务按每个独立资产分别调用内置工具；不因“批量”改用 CLI。共享参考可复用，但不同镜头的提示词和产物 ID 应分开。
5. 等待真实工具返回，按工具要求将结果展示给用户。实际文件返回后，复制到项目内的版本化资产路径；不猜测输出路径，不只留在默认生成目录。
6. 查看实际图片，检查身份、手/道具、构图、空间和文字。保存实际尺寸及 SHA-256，引用分镜中的真实路径。工具仅返回预览但无法取得文件时，不把项目资产标记已落地。

## 能力边界

- 不要求 `OPENAI_API_KEY`，不把工具路由固定为未确认的底层模型名。
- 内置工具不可用或失败时如实说明，保留提示词、引用和进度；用户明确改变工具约定前，不切换 CLI 或其他服务。
- 内置生成调用结果未知时先核对当前返回和已有文件；没有查单接口就说明无法查单，不编造任务号。
- 不为插件制作或安装自动生成图片。这份约定在实际图像创作请求时生效。
