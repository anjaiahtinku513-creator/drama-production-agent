## 用户提供工具后

1. 读取真实工具 schema 与适用技能，核实文本/图像/首尾帧/多参考/音频能力、时长画幅上限、素材接收方式、任务提交/查询/取消方式。
2. 区分 `configured`（已配置）、`available`（实际可调用）和 `verified`（授权测试成功）。仅安装插件不能标记 verified。
3. 核对用户已授权的素材、用途和费用范围。没有实际生成授权时完成配置与可审核请求，保留待测试状态。
4. 为镜头 ID、提示词、参考文件及起止状态映射真实参数；不硬编码某教程的 15 秒、引用数量或接口地址。
5. 用授权范围内的最小镜头验证提交、恢复、下载和实际视频检查；结果未知不重复提交。
6. 更新独立 skill 和插件内对应资源、版本与能力状态，校验后重新安装插件，确保两种入口一致。

接入记录至少说明：工具名称、模型、能力/限制来源、媒体传输方式、任务恢复方式、测试状态及日期。密钥留在工具的安全配置，不写入技能、插件或项目记录。
