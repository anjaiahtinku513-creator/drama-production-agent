# 空间、摄影与连续性导演

用于首帧图生视频、运动分镜、场景/布光规划和跨镜返修。通用方法改编自 travel-skill；场景范围扩展到短剧和漫剧。

## 首帧事实与规划事实

已有首帧时先看实际图，再记录前中后景、人物/道具位置、朝向/视线、可见出入口、路径、遮挡、机位、光源及风向。区分已存在、可以沿可见路径进入、没有依据不能新增的元素。看不见的空间不能用长镜头强迫模型补全。

尚未制作关键帧时可以先做空间方案，明确属于规划。关键帧产生后重新核对；不能把文字规划记成已完成首帧检查。文字分镜可用“待首帧核对”继续准备，实际提交需要的参考未绑定时不提交。

## 选机位与运动

先确定主体与叙事职责：跟随行动、观察反应、揭示线索或交代环境。再确定景别和可见范围，选择一个主运动或固定机位。

| 选择 | 适用条件 |
|---|---|
| 固定镜头 | 读表演、接触动作或等待变化；保持画框稳定 |
| 推进/后拉 dolly | 路径存在、距离和时间可达；透视随机位改变 |
| 横摇/俯仰 pan/tilt | 固定支点转向已有或已建立的空间 |
| 横移/跟拍 truck/tracking | 主体运动路径与摄影机通道清楚，背景视差合理 |
| 移焦 rack focus | 已有前后主体需要信息转移；不等于机位移动 |
| 绕拍/穿门/升降 | 环绕空间、门与高度变化有依据，必要时先试镜 |

运动描述包含起点→轨迹/速度→跟随对象→依次显露的信息→终点构图。不要把摇镜、平移和变焦混为一谈。一个主运动可以带连续小幅调整，不能在一次连续镜头中突然跳到另一地点。大环绕、穿越和复杂组合缺乏支持时改成拆镜或更小运动。

单镜连续空间与多镜剪辑要分开。模型支持且项目选择镜头组时，可写明确的内部切镜；每个内部镜头各自有起终状态。单镜图生视频稿不夹入多个无路径的独立机位。

## 有依据的布光

寻找窗、天空、灯具、火或反射的依据，先定环境曝光，再定主光方向、软硬和冷暖；补光控制暗侧，轮廓/背景光只在需要时增加。对话可以沿单窗侧光建立明暗；夜景可用已存在实景灯；火光和法术光交代局部变化与消退后的基础光。

不要把统一调色误写成所有地点同一光源。图生视频继承输入的阴影、天气、曝光与材质反射；变化需要有事件来源。体积光需要光源开口和雾尘介质，缺少则不加。

## 终态与切点

每镜记录主体站位/朝向/视线、双手和持物、动作阶段、服装/伤势、落地物与场景破坏、机位/方向、光线及声音尾部。下一镜继承需要延续的状态；明确时间/地点跳跃可以改变状态，但要有叙事或剪辑依据。

同一连续镜头内部也逐拍核对终态→起态：固定机位下，人物从画面中偏左变为中偏右，必须有可见移动或构图依据；仅另一人物后退不会自动改变未移动者的画面位置。先追踪各主体路径，再写相对距离，避免只检查全镜首尾而漏掉中间跳变。

同空间动作接续可用动作匹配；对话可用视线与正反打；跨地点优先分开制作，用声音桥或正常剪辑。遮挡转场仅用已有或沿可见路径带入的物件。实际尾帧和计划终态分别记录；前段重生后重新绑定后段参考。

## 故障定位

凭空入场先查首帧与路径；穿墙先查摄影路径；随机缩放先查主运动冲突；方向颠倒先查轴线；光线闪变先查源与曝光；衔接错位先查实际尾帧和状态继承。先修最早出错层，按 [生产与恢复](production.md) 追踪下游。
