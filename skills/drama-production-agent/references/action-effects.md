# 动作与特效导演

用于打斗、追逐、群战、武器接触和超自然效果。改编自 action-fight-prompt，并扩展为星幕的动作/法术状态交接。使用已确认故事决定输赢，不强制第一击失败或下一轮战斗。

## 动作因果与容量

先确定本段发生的剧情变化、双方起始位置、距离、朝向、支撑脚、左右手占用、武器数量、环境材质及允许的特殊物理。用“准备/试探→主要交锋→可见后果”安排节奏；比例按剧情调整。

每拍一组主要动作及必要反应。快动作可用约 2–3 秒阶段作为起点，但抓握、换手、施法、长台词与停顿应获得实际需要的时间。总时长依据项目和当前工具能力，不继承上游的 15 秒通道上限。

关键动作写清：起姿/力量来源 → 重心与支撑 → 手或肢体轨迹 → 接触位置 → 对方/物体反应 → 收势。下一拍依赖上拍结果；没有过程的换位、换手、落地与收剑需要补动作或拆镜。

## 反馈与空间

接触之后才出现材质和力量反馈。金属接触可以有撞击与振动，落脚可以扬尘，软组织受力可以退让；不要每拍都强加爆炸或场景破坏。环境变化记录进终态，下一镜不恢复原状。

人物左右与画面左右分别说明。动作轴线先建立，换轴用可见移动或明确剪辑。摄影机可固定以看清接触，也可沿已有路径跟拍；不沿用上游“打戏禁止全程固定”的绝对规则。看不清命中时先调整景别、遮挡和动作容量，不堆更多震动和粒子。

## 题材增量

- 近身对打：攻击路径、闪避空间、接触与重心改变可读；双方保持各自参考映射。
- 载具追逐：说明速度方向、转弯余量、轮胎/悬挂与惯性；声音和地表反馈随实际动作变化，不以沙尘代替路径。
- 群战：按可读人数分配先后和主次，其余角色保持背景行为；避免同拍多人各做复杂动作。
- 巨物或机甲：通过环境参照与不同景别建立比例，重要攻击分镜完成；机械与角色不可混淆。
- 仙侠/法术：来源→触发→发射位置→轨迹→目标→反应→余效消退。写明颜色、范围、遮挡、照明变化与世界观例外；允许腾空或传送时交代可见触发与落点，避免误当成模型跳变。

## 声音与慢动作

把力量、材质、生物声按需要绑定动作节点；音乐遵循项目设置。微慢动作只在有叙事作用的节点使用，给出时段，并把延长时间纳入本段总长；不机械要求每段使用。对白、撞击和配乐不要互相遮挡。

## 静态版本与验收

静态漫剧用起势、接触/关键结果、收势等必要关键帧表现动作，图片提示词各写一个确定瞬间；后期推拉不冒充完整打斗动画。动态结果必须连续播放关键接触和交接，检查穿模、武器复制、同手多物、力的方向、落点、特效来源和持物终态。文本规则通过不证明视频物理合格。
