# 创作与镜头规则

编剧阶段先读 [编剧与改编](story-development.md)，美术阶段读 [视觉资产](visual-assets.md)。对白/反应镜头读 [表演导演](performance-direction.md)，战斗/接触/特效读 [动作导演](action-effects.md)，分镜与首帧运动读 [空间摄影](spatial-camera.md)。简单微动可加读 [轻动作](light-motion.md)。下方规则负责共享交接，专项细则由这些模块维护。

## 1. 改编成可表演的故事

原著先做戏剧改编，不按自然段直接生成视频。用少量文字确认单集观看体验：谁要什么、谁如何阻止、关键选择改变什么、当集兑现什么、结束时留下什么压力。悬疑、喜剧、生活流可以有不同节奏，不强制每隔固定秒数反转。

长篇先建立与用户范围相称的分集地图；来源章节/片段引用跟随改编段落。未拿到的后文不假装已经分析。写明实质新增的情节，不把改写内容当成原著事实。

剧本包含场景、人物、可见动作、对白、必要画外音和声音。内心活动可通过选择、反应、物件或有意的旁白表现。删减不影响因果的重复；保留观众理解关键动作、证据和空间的时间。对白时长应在获得实际配音后校准，不能只按字数估算认定可播。

## 2. 两种参考：身份与风格

视觉设定保存角色 ID、稳定特征、造型变体、场景空间、关键道具及其状态。首次选择风格可比较少量视觉方向，确定后生成一张风格基准图；角色参考图控制身份，场景参考控制地理，风格图控制色彩材质与照明。多视图/表情图只在正反面切换或表情跨度确有需求时生成，不机械要求全套。

参考图必须实际存在、用途明确。引用上限由当次工具能力决定，避免把同一画面不需要的全角色库塞入模型。角色过多时拆镜或构图，不靠堆叠描述解决。

## 3. 镜头级可执行契约

每镜在分镜正文中记录：

| 字段 | 内容 |
|---|---|
| 镜头与来源 | EP001-S010；对应剧本场次/事件 |
| 戏剧职责 | 观众在本镜新增看到/理解什么 |
| 时长与构图 | 目标时长、画幅、景别、机位、镜头运动 |
| 输入参考 | 人物/造型、场景、道具、风格的真实文件或资产 ID |
| 起点 | 站位、朝向、持物、表情、已有信息 |
| 表演依据 | 触发、潜台词、构图可见信号、对白前中后或无声反应顺序 |
| 空间与摄影依据 | 已有/规划首帧、可见路径与遮挡、摄影机起点/轨迹/落点、光源 |
| 动作与反馈 | 力量/支撑、轨迹、接触、结果、必要材质/特效反馈；简单镜头按需 |
| 动作和终点 | 一项主动作及必要反应；终点如何进入下一镜 |
| 声音 | 说话者、原文、情绪、画外音、必要音效 |
| 关键帧 | 可冻结的画面，明确人物空间和道具状态 |

复杂多人物镜头可包含连续子动作，但要检查时长和注意力负担；太多则拆镜。首尾帧只有确需动作终点约束且模型支持时才生成，不为每镜硬加尾帧。

真人短剧额外检查视线、轴线、左右手、出入画方向、景别落实、说话触发后的情绪变化；背景人物不能夺走叙事焦点。风格化漫剧允许夸张，但不能破坏身份、动作因果和空间理解。

## 4. 逐镜与镜头组

需细控表演、道具或单镜返修时逐镜生成。相邻镜头共享场景、角色和连续动作且服务支持多镜叙事时，可合成镜头组。每组保留镜头 ID、内部时序、对白及引用关系；参数上限实时读取，不把某教程的 15 秒或引用数量当作通用常数。

镜头组降低调用次数但扩大返修范围。在预算、连贯性和可编辑性之间作出显式取舍。若供应商只返回一条合成片，单镜修改可能必须重做整组，不能假装能独立替换内部镜头。

## 5. 三种制作形态

- 静态漫剧：关键帧 → 实际配音 → 按对白和信息节奏设停留时间 → 轻量推拉/分层视差 → 音效音乐与字幕 → 剪辑。明确动态效果来自后期。
- 动态漫剧：关键帧验收 → 图生视频或多模态镜头组 → 动作与角色检查 → 声音 → 剪辑。
- 真人短剧：参考与空间确认 → 表演分镜 → 关键帧/视频 → 口型与声音同步检查 → 连镜剪辑。

模型原生对白若已达到要求就复用；若另配 TTS，确定视频静音/保留环境声及口型路径，防止双重人声。语言、口音、字幕文字分别配置。

## 导演提示词正文

分镜转为生成提示词时使用 [导演提示词标准](director-prompt-standard.md) 与其完整模板。上面的镜头契约是数据基础，不能用简表替代用户审核所需的完整人物、服饰、场景光线、逐拍动作情绪和交接正文。图片提示词保留确定瞬间；时序动作进入视频或后期计划。
