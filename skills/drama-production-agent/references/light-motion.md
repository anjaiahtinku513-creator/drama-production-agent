# 轻动作与环境镜头

用于已有关键帧的简单图生视频、反应、空镜和环境呼吸段。提取自 travel-photo-to-video；排序与声音遵循星幕的剧本和项目设置。

## 适用与退出

只有少量自然动作且不需要复杂接触、对抗或大幅表演时采用。抓握换手、战斗、快速跑动等转入 [动作导演](action-effects.md)；复杂情绪转折转入 [表演导演](performance-direction.md)。静态漫剧仅采用后期轻推拉或实际分层视差，写明效果来源。

查看已有图并完成 [空间检查](spatial-camera.md)。首帧定义身份、建筑、天气与光线；运动稿重点写变化，不重新设计已有画面。

## 运动选择

- 人像：眨眼、呼吸、轻微转头或已有姿态的自然延续；固定或很轻的推进。
- 行走：沿已有路径继续，速度、方向和衣物运动一致；不突然奔跑或主动看镜头。
- 建筑/室内：固定、小幅推进或横移，保持结构；无层次不硬加视差。
- 水面/树叶/衣摆/烟雾：选 1–2 项本图已有的环境微动，方向与场景条件一致。
- 细节：已有蒸汽或手部小范围动作可用，复杂手工操作另拆镜。

时长按本镜的信息、对白、停顿和工具能力选择。约 3–6 秒只是轻动作的参考范围，不是通用上限。已有剧情顺序优先；纯环境蒙太奇才按时间、色调、构图或声音优化顺序。

## 生成稿与检查

从统一视觉设定中选本镜必要约束，再写主运动→主体自然动作→环境微动→终态与稳定要求。正文通常几句即可表达运动层；作为完整导演稿的一部分时，不据此删去人物、场景、声音和交接分区。

不自动加入 ARRI、胶片、暖金青蓝、无字幕或无音乐默认值。检查主体与空间不漂移、动作不突变、环境运动方向合理、文字等核心信息稳定。后期合成与模型生成的动态效果分别标明。
