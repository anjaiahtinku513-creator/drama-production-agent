# 导演提示词标准

按[完整模板](../assets/director-prompt-template.md)编写详细交付稿，并用[虚构项目示例](director-prompt-example.md)核对细节。生成质量在取得实际素材后检查。

## 必须展开的分区

1. 【基础信息】：来源和改编新增、项目标识、供应商/模型、时长与分段、实际画幅分辨率、语言、核心剧情冲突及本段可见结果。商业字段只在项目使用时填写。
2. 【参考图职责锁定】：实际文件/资产与出站字段或引用编号一一对应，分别说明身份、服装、场景、风格职责及冲突优先级。一张图可承担多种职责；禁止虚构 @Image2 或无图角色库。
3. 【摄影机与画质约束】：风格、景别、机位、镜头运动、景深、轴线、运动模糊、剪辑原则。一个镜头一个主要机位运动，不同时要求固定和持续手持晃动，不虚标分辨率。
4. 【文字与声音约束】：字幕/画内文字、逐人声线、语言口音、说话人与口型、旁白、配乐及音效避让。对白逐句给出，外语另附中文审核译文；无对白明确写无。
5. 【人物、服装与道具锁定】：逐人明确脸、发型、年龄感、身材、服装颜色与层次、领肩袖腰摆结构、材质反光与垂坠、鞋饰、武器数量和持握手、初始状态。
6. 【场景与光线锁定】：地点、前中后景布局、地面、人物相对位置、天气风向、主光和轮廓光方向冷暖、阴影、特效引起的局部变化及消退后的基础照明。
7. 【动作、服饰与法术物理约束】：左右手/支撑脚/道具占用、重力惯性、接触与收势。非仙侠改为该题材的动作和特效因果，不强加法术。
8. 【分镜与情绪递进】：每拍时间、构图及目的、摄影机、起始状态、动作、特效、神态、情绪变化、对白、语气、音效、结束结果、交接。
9. 【跨段首尾帧与剪辑交接】：实际首尾帧绑定、人物/双手/道具/机位/光线/运动方向终态与起态、声音承接及切点。
10. 【发布文案】：与生成指令分开。需要发布文案时给当地语言完整文案及恰好五个相关非品牌标签；有外语时附中文审核翻译。正文不得冒充已获原作授权或已公开发布。

## 专项方法如何进入完整正文

先按任务读取 [视觉资产](visual-assets.md)、[表演](performance-direction.md)、[动作特效](action-effects.md)、[空间摄影](spatial-camera.md) 或 [轻动作](light-motion.md)。完整分区保持不变，专项规则改变具体内容：

- 视觉方案进入人物/场景锁定；角色参考、场景参考、风格与剧情关键帧用途分开。
- 表演进入每拍神态、对白与语气：由事件和潜台词选择可见信号，保留台词后反应；远景不依赖看不清的微表情。
- 动作进入物理约束与逐拍正文：明确接触先后、力量和环境反馈，法术使用项目世界观；固定机位可用于看清动作。
- 摄影进入场景与逐拍机位：实际首帧检查、起点/路径/落点、光源、轴线和交接。单镜连续运动与镜头组内部剪辑分别编写。
- 轻动作只简化运动层，不能据此省略完整审核稿；静态形态把时序分配给分镜、配音和后期，各图片稿仍只写确定瞬间。

规划与实际观察分别标明；待绑定的参考不编造成文件。已确认台词或身份只优化指定层时保持原文。对不适用项目简短说明，不为了分区完整虚构法术、声音或大量环境反馈。

## 细节可执行性

每拍动作写成“起始姿势→支撑脚→哪只手→运动路径→接触/命中→可见结果→收势”。无手部或非人角色按实际结构适配。人物左右与画面左右分别说明；换手、收剑、掏物、合掌需要可见过程与足够时长。

每拍一项主要动作及必要反应。复杂连招可以拆拍；不要把细节多写成同时发生的动作多。秒数首尾连续且合计等于本段时长，台词要留换气与反应时间，生成后再按实际语音校准。

情绪用目光、眉毛、嘴角、下颌、肩部和呼吸承载，说明“因何事件从什么变成什么”。不能只写“愤怒”“震撼”“电影感”。

特效写成“来源→触发动作→发射位置→路径→目标→反应→环境反馈→消退”，限定颜色、规模、时序和遮挡范围，关键命中与结果可读。夸张物理必须是明确的世界观设定。

衣服、持物、落地道具、伤损与场景破坏在镜头间延续。提前规划的画面不是实际生成尾帧；前段重生后，后段首帧必须重新绑定并校准，未得到时明确待绑定，不伪造 URL。

## 审核稿与生成稿

用户要求看提示词：回复展开完整审核稿（共享约束＋所有片段所有镜头），同时可附文件。仅当用户明确要求摘要或局部修改时缩小正文范围。

实际提交：每段独立复制必要全局锁定、真实参考绑定和本段逐拍内容。制作说明、待办、发布文案、审核翻译及质量声明按工具用途隔离，不混进应朗读的对白。输入长度受限时保留完整审核稿，按模型容量拆分或编译，并说明差异，不能悄悄退回梗概。

用户认可格式只表示文字标准通过，不等于角色图、生成片、声音或剪辑已验收。工具/模型选择与费用沿用当前项目授权，不把示例参数变成所有项目的配置。

## 交付前核对

- 分区与所有镜头已具体填写，无未解释占位词、虚构图片或“同上”；对白、情绪与动作时间相容。
- 双手占用、武器数量、脚步与轴线无冲突；动作及特效因果先后清楚。
- 参考实际存在或明确待绑定；跨段状态可追踪，光线与道具不重置。
- 完整审核稿与独立生成稿内容一致；发布文案独立。
- 将文字审核、媒体技术、视觉连续性、完整播放、实际听音分别报告；提示词目标不能作为质量证据。
