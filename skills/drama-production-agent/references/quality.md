# 质检、剪辑与交付

## 关键帧先验收

检查身份/造型、脸手与肢体、空间站位、持物状态、画风、景别、意外文字；逐项给出可定位观察。自动评分只能辅助排序，不能把任意分数视作审美真理。视觉分析报错时记未完成，不能放行后声称验收通过。

## 视频验收

1. 技术检查：文件可解码，时长/画幅/分辨率符合本项目，帧率与音轨正常；检测到黑帧不直接判错，核对是否有意转场。
2. 视觉检查：检查首、中、尾及动作交接位置；关键动作应连续播放，稀疏抽帧不能证明全程稳定。检查换脸、闪变、手/道具复制、空间跳变、动作终点及字幕污染。
3. 音频听检：实际听取对白和混音，核对说话者、字词、漏句、重句、音量、截断、口型时序及背景音乐遮挡。仅 ffprobe 音轨信息不算听检。
4. 记录不确定范围：如只看抽帧、没听声音、没看完整片，必须保留未验收结论。

## 专项导演检查与最小返修

| 检查层 | 要观察的证据 | 优先返修 |
|---|---|---|
| 剧本与信息 | 行动、证据和结果是否让观众理解；角色是否使用尚未知信息 | 剧本因果/分镜信息分配 |
| 视觉资产 | 实际身份、服装、道具数量、材质、比例与选定风格 | 资产或关键帧，追踪引用镜头 |
| 表演 | 触发早于反应、目光对象、对白前中后、声音与表情强度 | 表演/声音层，不擅改已定台词 |
| 动作特效 | 连续播放接触、支撑/持物、反馈、力量方向和特效来源 | 起始构图、动作容量或接触链 |
| 空间摄影 | 首帧路径、机位、遮挡、光源、轴线、终态 | 空间/摄影方案或关键帧 |
| 轻动作 | 主体和建筑稳定，微动有依据，环境方向一致 | 减少运动要求或修输入图 |
| 跨镜/跨集 | 持物、伤势、场景破坏、信息/关系与声音承接 | 最早错误状态及受影响依赖 |

没有相应媒体时只能评审文本可执行性，不声称完成表演或物理验收。静态形态检查关键帧、配音与后期时间线；动态形态关键动作和表演要连续观看。修完复查相关交接及最终所选版本，不把废弃候选再次当作完成证据。

## 剪辑

先按实际对白和镜头终点建立时间线，再处理节奏。转场应有叙事原因；J/L cut 在声音先后关系有益时使用，不强制每镜应用。统一角色声音与字幕，保留必要环境声，避免原生对白与后配音重叠。

静态漫剧按阅读和听觉节奏安排停留，不平均分配所有图片时长。合成字幕与画内必要文字分别处理；确认文字清晰且不挡脸或关键道具。

完整播放整集，检查集首是否清楚、因果是否可理解、动作能否接上、情绪是否成立、结尾是否兑现。没有播完整集，最终验收仍未完成。若用户只要素材包，不强行追加剪辑与成片。

## 交付格式

给出成片/素材的可访问位置，概括内容和规格；注明完成的技术、视觉、声音检查及剩余问题。保留用户需要的剧本、分镜、可编辑工程/时间线、字幕及素材映射。外部发布是单独范围，不因成片通过自动上传或发布。

交付状态：
- 创作资料完成：文字和计划已就绪，媒体未生成。
- 素材完成：生成文件已获得，验收状态分别报告。
- 成片待验收：已合成但还有未完成检查。
- 成片已验收：真实成片及所用依赖适用检查通过，无未解决问题。

## 提示词交付检查

文字准备的交付也须按 [导演提示词标准](director-prompt-standard.md) 检查：完整分区、逐拍时序、左右手/道具占用、人物表情与情绪因果、法术/动作路径、场景光线、真实参考与首尾交接。用户要求看稿时直接展开全部审核正文，可另附完整文件，不仅给链接或局部示例。

完整审核稿允许集中写全局锁定；交付给生成工具的每段文本必须自包含。未绑定素材明确标注；文字标准通过与成片验收分别记录。
