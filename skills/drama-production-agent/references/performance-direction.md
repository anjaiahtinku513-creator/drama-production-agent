# 表演导演：潜台词变成可观察行为

用于对白、反应、无声情绪镜头和局部表演修改。改编自 emotion-performance-director；真人方法向漫剧的扩展属于星幕适配。

## 判断与编排

1. 找触发事件及潜台词：人物想争取、隐藏、拒绝或保护什么？已经发生什么使他改变？已有明确设定优先，推断只服务本镜，不擅自新增背景事实。
2. 从目光、呼吸、面部、身体和声音中选少量主要信号，通常 2–4 项足够。信号由同一心理原因引出，不让人物同时颤抖、哭泣、喊叫和挥手。
3. 编排说话前的准备、说话中的表达、说话后的余反应。无对白镜头按触发→反应→残留状态组织，不硬填台词三段。
4. 检查画面能否看见该信号。远景不依赖瞳孔和细微嘴角；近景动作别同时要求脚部细节。重要反应需要时调整分镜，局部表演修改则先在已有构图里选择可见信号。
5. 删除不影响情绪理解的重复手势，给沉默和停顿留下时间。

台词原文、角色身份、场景和机位沿用已确认稿；只优化表演时不改变这些层。视线对准已建立的对手或物件，不默认看摄影机。悲伤不自动加眼泪；克制以实际动作幅度体现。

## 三种制作形态

| 形态 | 表演落点 |
|---|---|
| 真人短剧 | 自然微表演、合理呼吸、语气与台词后残留反应，口型与音频检查 |
| 动态漫剧 | 在画风内放大可读表情和姿态，允许明确的漫画符号或变形设定，但不丢角色身份和反应因果 |
| 静态漫剧 | 选择情绪转折的确定瞬间写图片提示词；另在分镜/剪辑单安排表情帧变化、配音停顿和停留时间 |

同一角色的习惯和强度可以跨镜继承，但受不同事件触发时不重复同一表演。静态画面不能在一条图片提示词里连续经历三个表情。

## 写进导演稿

在逐拍正文自然写出触发、可见信号、对白原文与语气、结束反应。内部分析不用全搬到生成稿；完整导演审核稿仍依照用户要求保留所有分区。

示例仅示意方法：人物看到证据后停住目光，吸气后抬眼看向对方；说固定台词时压低声音，句末不移开视线，等待回答。是否收手、流泪或后退由本场潜台词、站位和时长决定。

## 检查与返修

检查事件是否先于反应、信号是否可见、说话前中后是否有顺序、强度是否符合人物与画风、台词与动作是否争抢时间。实际视频要看连续表演和听声音；只有静态帧不能证明呼吸、语气或口型合格。问题在声音时优先修音频，在姿态或目光时检查关键帧与表演稿，再决定重生范围。
