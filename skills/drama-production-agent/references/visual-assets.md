# 美术与视觉资产导演

用于剧本资产提取、统一风格、角色/场景/道具参考提示词。方法改编自 Director Skills 的 cinematic-asset-prompts；来源与适配见 [设计来源](design-sources.md)。

## 先定视觉事实

读取剧本与已有参考。已有身份、配色、画风和素材优先；缺少时从叙事类型、人物处境和世界观推导方案。统一方案说明线条或渲染质感、主辅色、材质、光源逻辑、画面对比和需要避免的风格。场景昼夜和局部特效可以变化，不要求每张图使用相同光线。

风格选择参考：都市情感可用柔和窗光和自然肤质；悬疑可强化局部可见信息及明暗关系；历史题材关注年代材质和实际灯火；玄幻先定义写实/水墨/动画及超自然规则；科幻说明结构与机械逻辑。以上是起点，不能覆盖用户已经选定的风格。

## 建立实际需要的资产清单

在视觉设定中为每项资产记录 ID、剧情作用、稳定特征、变体/状态、共享设计语言、实际参考文件及验收状态。未生成时写待制作，不能填假路径。角色衣服换色、受伤、武器损坏属于变体；角色身份保持稳定。

| 类型 | 参考图的用途与构图 | 与剧情关键帧的区别 |
|---|---|---|
| 角色定妆 | 正面全身、中性姿态、轮廓清楚；必要时加面部或侧背面 | 不在同一张定妆图塞入战斗与多场剧情 |
| 场景参考 | 空间全貌、出入口、地面与重要物件；无人空镜便于复用 | 剧情关键帧可以有人，需明确站位和视线 |
| 道具/武器 | 看清结构、数量、尺寸、材质和持握位置；视角按用途 | 接触动作和持物归属由镜头确定 |
| 载具/机械 | 轮廓与比例、动力/关节及关键接口，必要侧视 | 不机械要求所有载具采用同一画幅 |

多视图与表情库只为实际镜头需要制作。涉及多人的画面，先选择本镜需要的角色与状态，再组合；不要把整库作为每镜输入。

## 可复制的资产提示词

每项独立组织：共享风格 → 资产身份/功能 → 从整体到局部的结构 → 配色材质 → 与故事有关的使用状态 → 必要限制 → 视角与构图。旧化强度从剧情推导，新衣和洁净室不用强加划痕。写实采用自然肤质；动画采用已定线条与渲染方式。

默认给中文可执行稿；项目需要英文模型输入或用户要求时另给对应英文稿。画幅等参数映射到真实工具字段，不把 Midjourney 的 --ar 后缀用于 Codex 内置工具，不以“8K”文字声称实际分辨率。

资产制作按 [内置图像生成](builtin-image.md) 执行。用户仅要求设计或提示词时不生成。资产验收看实际图：身份、轮廓、服装结构、数量、空间、画风与意外文字；文字描述完整不等于资产已通过。

## 交接

关键帧只绑定本镜需要的实际资产版本，分别说明身份、造型、场景与风格职责。参考冲突按信息类别确定依据，不用一张风格图替换角色身份。资产变更先列受影响镜头；通过 [生产与恢复](production.md) 保留旧版并使有关结果失效。
